# 開發交接日誌 (2026-05-24)

## 今日進度：非同步戰鬥演出系統與老奶奶命名重構

1. **實作 SkillDirector 時序導演**：
   - 建立 [SkillDirector.gd](../../MarbleGame/gameplay/combat/SkillDirector.gd) 作為 `CombatUI` 的子節點。
   - 使用 `await` 與 `create_tween` 精確調度：「卡片縮放發動 ➔ 投擲球飛行 ➔ 受擊抖動閃紅 ➔ 生成扣血/回復飄字 ➔ HP 條與數值平滑遞減」的非同步表演。

2. **實作飄字與投擲物元件**：
   - **傷害與治療飄字**：[DamagePopup.tscn](../../MarbleGame/gameplay/combat/DamagePopup.tscn) & [.gd](../../MarbleGame/gameplay/combat/DamagePopup.gd)，具備彈性 Bounce、隨機 X 軸偏移、向上飄移與自動淡出銷毀。
   - **旋轉投擲物**：[Projectile.tscn](../../MarbleGame/gameplay/combat/Projectile.tscn) & [.gd](../../MarbleGame/gameplay/combat/Projectile.gd)，支援載入卡牌動物圖示或預設彈珠，具有立體拋物線縮放與高速旋轉。

3. **老奶奶命名重構**：
   - 修改 [CombatUI.tscn](../../MarbleGame/gameplay/combat/CombatUI.tscn)，將左側頭像 `CatSprite` 正式重命名為 `GrandmaSprite`，並將預設的玩家名稱標籤文字改為 `"老奶奶"`。

4. **解耦戰鬥主邏輯與演出**：
   - [CombatManager.gd](../../MarbleGame/gameplay/combat/CombatManager.gd)：重構 `trigger_skill_from_slot` 與 `enemy_turn_tick` 成為原子邏輯計算，返回內含我方卡牌、新舊生命狀態轉變、我方與敵方反擊明細之「戰鬥收據（receipt Dictionary）」。
   - [Main.gd](../../MarbleGame/core/Main.gd)：升級 `_on_slot_hit` 流程為協程（`async await`），攔截邏輯計算後的戰鬥收據，先播我方卡牌縮放與丟球，再逐一等待敵方反擊表演，最後解除動畫鎖做狀態對齊。
