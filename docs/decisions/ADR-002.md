# ADR-002: 從動態生成轉向手動 Prefab 佈置 (2026-04-13)

## 狀態
已決定 (Accepted)

## 背景
原專案透過代碼動態生成釘子 (Pegs) 與計分槽 (Slots)。雖然靈活，但對於「追求美感與特定排列」的彈珠台設計極度不友善，且代碼量巨大難以維護。

## 決策
廢止 `MarbleTable.gd` 中的動態生成函數。建立 `Peg.tscn`, `Divider.tscn`, `ScoreZone.tscn` 預製體。

## 實踐規則
- 主場景 `MarbleTable.tscn` 僅作為容器，不包含生成腳本。
- 使用者與 AI 應透過編輯器視覺化拖拉/複製貼上來佈置盤面。
- 大量佈置後，修改原件 (Base Prefab) 以同步更新。
