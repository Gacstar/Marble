# ADR-003: 基於 Tween 的物理發射感應機制 (2026-04-13)

## 狀態
已決定 (Accepted)

## 背景
為了讓拉桿具有絲滑的「蓄力回彈」感。曾嘗試使用 `apply_central_impulse` 直接賦予彈珠速度，但這會讓「實體推撞」的樂趣消失，且物理回饋不夠直觀。

## 決策
回歸實體推撞 (Physical Pushing) 邏輯。使用 `Tween` 推動拉桿 (AnimatableBody2D) 高速回彈以撞擊球體。

## 後果 (Consequences)
- 使用者可以透過控制 `Tween` 的 `duration` (如 0.06s 或 0.1s) 來線性控制物理力道。
- 因為使用了 Box2D，即使在高速 Tween 拍擊下，彈珠也不會穿模进入拉桿內。
