# 2026-07-29 卡牌與技能本地網頁編輯工具開發日誌

本工作會話中，我們為 `cards.csv` 與 `skills.csv` 實作了一個高質感的本地視覺化編輯工具，解決了人工修改 CSV 易出錯（前導零丟失、欄位錯位）且沒有預覽的痛點。

---

## 🏗️ 系統架構與職責

本次開發新增與重構了以下檔案：

1.  **[啟動卡牌編輯器.bat](file:///d:/GodotProject/Marble/啟動卡牌編輯器.bat) (專案根目錄)**
    *   **職責**：一鍵背景無感啟動。
    *   **技術**：使用 PowerShell 隱藏視窗參數，雙擊執行時**不會出現 CMD 黑色終端機畫面**，直接在背景拉起 Python 伺服器並自動開啟網頁。不佔用 IDE 的 AI 代理人通道。
2.  **[card_editor_server.py](file:///d:/GodotProject/Marble/tools/card_editor_server.py) (輔助工具目錄)**
    *   **職責**：本地 CSV 讀寫與圖片 Serve API。
    *   **功能**：
        *   讀取並提供 `/api/cards`、`/api/skills` 與 `/api/textures`。
        *   將遊戲貼圖 `MarbleGame/assets/textures/` 映射為 Web 路由供網頁預覽。
        *   每次寫入前，自動在本地建立 `*.csv.bak` 備份，防止資料因寫入出錯損毀。
        *   **自我銷毀**：提供 `/api/shutdown`，接收到請求後延遲 0.5 秒直接終止進程退出。
3.  **[card_editor.html](file:///d:/GodotProject/Marble/tools/card_editor.html) (輔助工具目錄)**
    *   **職責**：Glassmorphic 風格的雙頁籤 SPA 編輯器。
    *   **功能**：
        *   **卡牌管理**：卡牌清單、欄位編輯、中文技能動態下拉選單、Live Card Preview（圖片、漸層技能標籤與 slots 發光預覽）。
        *   **技能管理**：技能清單、PS 調色盤拾色器與 Hex 色號雙向同步連動。
        *   **自銷毀信號**：監聽 `pagehide` 事件，當關閉分頁或視窗時，透過 `navigator.sendBeacon('/api/shutdown')` 觸發伺服器自動終止退出。

## ⚡ 本次開發避坑指南 (Gotchas)

在未來的開發或重構中，請務必注意以下地雷：

1.  **JS 閉包與動態 State 鎖死 (Slots 編輯器)**
    *   *地雷*：若按鈕點擊事件的閉包（closure）捕獲了生成時的 local 變數（如 `normalizedStr`），修改後回寫到 card 物件但沒有更新該 local 變數，會導致後續點擊時依然讀取舊的變數，造成「只有第一次點擊生效，後續無反應」。
    *   *對策*：在 `btn.onclick` 內部，每次都實時透過 `cardsData.find` 尋找最新的卡牌狀態並進行修改，修改完成後立刻重新呼叫 `renderSlotsEditor` 重新生成整個按鈕組以確保狀態同步。
2.  **Beacon 傳送空 Body 與 JSON 解析**
    *   *地雷*：網頁關閉時，`navigator.sendBeacon` 會送出一個 POST 請求但沒有 request body。如果伺服器在 `do_POST` 頂部一律進行 `json.loads` 解析，會報錯 400。
    *   *對策*：在後端 `do_POST` 解析 JSON 前，優先特判 `/api/shutdown` 路由，若匹配則直接發送響應並啟動自我銷毀，不進行任何 request body 的讀取與解析。

## 💡 使用與對接流程

1.  **開啟工具**：在 Windows 檔案總管雙擊 [啟動卡牌編輯器.bat](file:///d:/GodotProject/Marble/啟動卡牌編輯器.bat)。網頁會自動跳出，並直接載入所有專案 CSV 與貼圖資源，無需點選目錄，亦無 CORS 警告。
2.  **編輯與存檔**：直接在網頁修改卡牌與技能，點擊右上角「儲存所有變更」存檔。
3.  **關閉工具**：直接將瀏覽器分頁關閉。背景伺服器在一秒內便會自動關閉消失。
