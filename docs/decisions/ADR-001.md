# ADR-001: 物理引擎遷移至 Box2D (2026-04-13)

## 狀態
已決定 (Accepted)

## 背景
Godot 4 內建的 2D 物理引擎 (GodotPhysics2D) 在處理高速小剛體（彈珠）時，即便開啟了 CCD 與提高物理幀率 (180Hz)，仍會頻繁發生穿門、抖動與位移偏差。

## 決策
全面停用內建 2D 引擎，改為導入 `godot-box2d (GDExtension)` 插件。

## 後果 (Consequences)
- **正面:** 徹底解決了 100% 力的發射與碰撞時的穿透問題。物理算式更加穩定，不需要額外的防穿模代碼。
- **負面:** 需要在所有開發環境中正確安裝 `addons/godot-box2d`。且 Box2D 的力道傳導極其精準，過往為了彌補引擎缺陷而存在的「暴力推力」需適度下調。
