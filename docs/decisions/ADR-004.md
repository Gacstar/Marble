# ADR-004: 卡牌戰鬥與牌堆循環機制 (Card Battle & Deck Cycling)

## 狀態
已接受 (Accepted)

## 上下文 (Context)
原本的彈珠台僅具備基礎的怪物 CD 與「得分換血」機制。為了增加遊戲的隨機性、策略深度以及「Roguelike」風格的重複遊玩價值，需要一個更動態的機制來取代單純的得分。

## 決策 (Decision)
1.  **卡牌觸發機制**：不再以得分多寡決定傷害，而是將底部槽位 (Slots) 賦予「技能 A (基礎)」與「技能 B (強力)」兩種屬性。傷害由當前所選卡牌的固定數值決定。
2.  **牌堆循環系統 (Deck Cycling)**：
    -   玩家手持 5 張牌，另外 3 張牌放在牌庫。
    -   一旦卡牌觸發傷害（球進洞），該卡牌立即進入牌庫底。
    -   系統自動從牌庫頂抽出一張新牌填補空缺。
3.  **視覺同步**：卡牌必須具有即時色塊地圖，與彈珠台槽位的物理顏色指示燈 (Indicator) 保持 1:1 同步。
4.  **物理優化**：為配合 Box2D 插件，全面拆解並簡化複雜碰撞體，強制使用 CCW 繞線，以解決穩定性問題。

## 後果 (Consequences)
-   **優點**：遊戲體驗從「隨機得分」變成「精準瞄準」，玩家需要根據當前持有的卡牌組合不斷調整射擊策略。
-   **優點**：牌堆循環增加了變數，避免單一卡牌過強或戰術僵化。
-   **缺點**：UI 開發成本增加，需要管理多種動物圖標、色塊渲染以及複雜的牌堆邏輯信號串接。
